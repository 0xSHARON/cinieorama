### Non-Hosting & Embedding Statement

1. **No Files Stored:**  
   CINIEORAMA does not host, upload, scrape, store, encode, or maintain any video files, media streams, MP4 files, HLS streams, or torrent files on any server, proxy, or cloud cache.

2. **Index of Public Sources:**  
   The application acts strictly as an aggregator of publicly available web embed links and queries publicly accessible metadata from third-party APIs (including [The Movie Database - TMDB](https://www.themoviedb.org/)).

3. **External Responsibility:**  
   All video streams displayed inside the player are served directly from independent, external third-party CDN domains that are not owned, operated, controlled, or affiliated with the creators of this software. ### Copyright Infringement & DMCA

If you are a copyright owner or an agent thereof and believe that any content linked or embedded violates your copyrights:

- Because CINIEORAMA does not host any media files, sending a takedown notice to this repository will not remove the media from the internet, as the files reside on independent third-party servers.
- To permanently remove the content, you must contact the webmaster or hosting provider of the external streaming domain where the file is physically hosted.
- If you wish for a specific third-party embed domain to be delisted from this software's default server lineup, please open an issue or pull request, and maintainers will promptly evaluate the request.
